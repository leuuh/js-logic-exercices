# 🚀 JS Logic Exercices

Repositório com exercícios de lógica em **JavaScript** para prática de algoritmos e resolução de problemas clássicos.

---

## 📋 Exercícios

### 1. **multiplos.js** - Soma de Múltiplos
Soma todos os números menores que 1000 que são múltiplos de 5 ou 7.

**Entrada:** Nenhuma (valores fixos)
**Saída:** `233168`

```javascript
console.log(sumultiplos()); // 233168
```

---

### 2. **indices.js** - Índices do Maior e Menor
Encontra os índices do maior e do menor valor em um array numérico.

**Entrada:** `[2, 3, 1, 10, 3, 4]`
**Saída:** `{ indiceMaior: 3, indiceMenor: 2 }`

```javascript
console.log(encontrarIndicesMaiorEMenor([2, 3, 1, 10, 3, 4]));
// { indiceMaior: 3, indiceMenor: 2 }
```

---

### 3. **MDC.js** - Máximo Divisor Comum
Calcula o Máximo Divisor Comum (MDC) entre dois números usando o algoritmo de Euclides.

**Entrada:** `48, 18`
**Saída:** `6`

```javascript
console.log(calcularMDS(48, 18)); // 6
```

---

## 🛠️ Como Executar

Certifique-se de ter o **Node.js** instalado. Depois, execute os arquivos com:

```bash
node multiplos.js
node indices.js
node MDC.js
```
